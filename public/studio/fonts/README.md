# Studio fonts

These font files are self-hosted and are not fetched from third-party services at runtime.

- `noto-serif-sc-*`: Noto Serif SC, licensed under SIL Open Font License 1.1. See `OFL-Noto-Serif-SC.txt`.
- `lxgw-wenkai/`: LXGW WenKai Screen webfont package 1.7.0 (font version 1.250.2). The typeface is licensed under SIL Open Font License 1.1; the webfont packaging is MIT licensed. See the license files in that directory.
- `smiley-sans/`: Smiley Sans 2.0.1, licensed under SIL Open Font License 1.1. See `smiley-sans/OFL.txt`.

The two optional editor fonts use `font-display: swap`. LXGW WenKai is split by Unicode range, so browsers download only the ranges needed by the current document.
