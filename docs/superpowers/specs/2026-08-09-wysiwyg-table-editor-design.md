# 所见即所得 Markdown 表格编辑器设计

## 目标

在 Markdown 编辑器工具栏加入“表格”按钮。用户可以在弹窗中选择列数和数据行数，
插入标准 GFM Markdown 表格，并在即时排版模式中直接编辑单元格。所有内容和结构
操作必须写回 Markdown，继续使用现有的撤销、自动保存、草稿、导出和预览链路。

## 创建表格

- “表格”按钮打开现有风格的无障碍弹窗，关闭后焦点返回按钮。
- 弹窗包含“列数”和“数据行数”两个数字输入框。列数范围为 2–8，默认 3；
  数据行数范围为 1–20，默认 2，表头不计入数据行数。
- 确认后插入标准 GFM 表格块。表头依次为“列 1”“列 2”等，数据单元格使用
  “内容”占位文本，分隔行使用 `---`。
- 空选区时在光标处插入表格；非空选区时保留选中文字并在选区末尾插入表格。表格
  使用空行与前后正文隔开；插入后聚焦第一个表头单元格并选中其默认文本。
- 编辑器禁用时不能打开弹窗或插入表格。

## 即时排版编辑

- 源代码模式始终显示原始 GFM Markdown，不渲染交互式表格。
- 即时排版模式把完整有效的 GFM 表格替换为真正的 `<table>` 表格组件。表头和
  数据单元格使用单行输入控件；分隔行不单独显示。
- 单元格输入实时转换为精确的 Markdown 文本变更，并通过 CodeMirror 事务触发现有
  `onChange` 和自动保存，不维护第二份文章状态。
- 单元格禁止真正换行；输入的竖线转换为 `\|`。显示时再还原转义，保证切换源码、
  预览和导出时内容一致。
- 表格 Widget 使用 CodeMirror 的 `updateDOM` 复用已有 DOM。普通输入写回后不替换
  当前输入框，并保留 `selectionStart`、`selectionEnd` 和焦点。
- 中文输入法在 `compositionstart` 到 `compositionend` 期间只更新输入框，组合完成
  后一次写回 Markdown，避免拼音候选过程被重建。

## 键盘、撤销与结构操作

- `Tab` 和 `Shift+Tab` 在单元格间前后移动，最后一个单元格不会隐式创建新行。
- 表格输入框内的 `Cmd/Ctrl+Z` 与重做快捷键交给 CodeMirror 的 `undo` / `redo`，
  不使用浏览器输入框自身的独立历史。
- 当前聚焦单元格决定结构操作目标。表格控制栏提供“添加行”“删除行”“添加列”
  和“删除列”：
  - 添加行在当前数据行下方插入一行；当前为表头时插入第一条数据行。
  - 表头不可删除，且至少保留一条数据行。
  - 添加列在当前列右侧插入；删除列至少保留两列。
  - 不支持合并单元格。
- 每个结构操作用单个 CodeMirror 事务重写当前表格块，因此可以一步撤销并保持周围
  Markdown 不变。操作后焦点移动到最接近原位置的有效单元格。

## 代码边界

- `markdown-commands.ts` 负责纯函数表格模板生成、块插入和选区计算。
- 独立的表格模型模块负责解析、转义、单元格替换及行列增删，不依赖 React 或 DOM。
- `live-markdown.ts` 只负责识别 GFM `Table` 节点、建立 Widget 和派发 CodeMirror
  事务；表格 DOM 组件不保存权威正文。
- `MarkdownEditor.tsx` 负责弹窗状态、工具栏入口和插入后焦点交接。
- 复用现有 `AccessibleDialog` 和 IMX Studio 视觉变量，不引入 IMX 主题源码依赖，
  不改变草稿格式、文章包格式或预览渲染器。

## 可访问性与错误处理

- 弹窗具备标题、标签、焦点圈定、Escape 关闭和焦点恢复。
- 每个单元格输入框使用“第 N 行第 M 列”作为可访问名称；结构按钮名称明确说明
  作用对象，并在达到行列下限时禁用。
- 数字输入在提交时再次校验并限制到允许范围；无效输入不会生成表格。
- 只有完整有效的 GFM 表格进入 Widget 模式；不完整表格保留 Markdown 源文，避免
  隐藏无法可靠编辑的内容。

## 验证

- 单元测试覆盖默认和边界尺寸模板、独立块插入、单元格转义、行列增删及周围正文
  保持不变。
- 组件测试覆盖弹窗焦点、输入范围、禁用状态、插入后焦点和源码模式切换。
- Widget 测试覆盖普通输入、中文组合、DOM 复用、光标保持、撤销重做和结构事务。
- Playwright 在 Chromium、Firefox、WebKit 上覆盖鼠标编辑、Tab 导航、撤销、
  行列增删、自动保存、窄屏无横向页面溢出以及预览表格内容。
- 最终运行 lint、类型检查、完整单测、独立性检查、构建及相关三浏览器 E2E。
