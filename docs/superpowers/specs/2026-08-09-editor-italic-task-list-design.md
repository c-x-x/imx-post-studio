# 编辑器斜体与可交互任务列表设计

## 目标

在现有 Markdown 编辑器工具栏加入“斜体”和“任务”命令，并让即时排版模式中的
GFM 任务列表复选框可以直接点击。点击结果必须写回 Markdown 正文，并沿用现有的
自动保存流程。

## 交互

- “斜体”把选区转换为 `*选中文字*`，并保持选中文字的选区。
- “任务”把选区转换为 `- [ ] 选中文字`；空选区生成可继续输入的空任务。
- 即时排版模式把 `- [ ]` 与 `- [x]` 渲染为未选中和已选中的复选框。
- 点击复选框只切换对应任务标记，并通过 CodeMirror 事务触发现有 `onChange` 和
  自动保存；不重建编辑器，不修改其他文本。
- 源代码模式保留原始 Markdown，不显示交互式复选框。
- 编辑器禁用时，工具栏命令和任务复选框都不可修改正文。

## 实现边界

- 在 `markdown-commands.ts` 增加斜体和任务命令，保持纯函数和现有选区契约。
- 在 `live-markdown.ts` 为 GFM `TaskMarker` 添加安全 DOM 复选框组件。组件只携带
  标记的文档位置和当前状态，点击后派发精确的 `[ ]` / `[x]` 文本替换事务。
- 在 `MarkdownEditor.tsx` 增加两个工具栏入口，并把禁用状态传给即时排版扩展。
- 不改预览渲染、导出格式、草稿数据结构或 IMX 主题仓库。
- 当前未提交的标题下划线修复继续保留，并与本功能共同回归验证。

## 验证

- 单元测试覆盖斜体与任务命令的 Markdown、选区和空选区行为。
- 组件测试覆盖工具栏入口以及禁用状态。
- 即时排版测试覆盖未完成/已完成任务的渲染与源代码模式不替换标记。
- E2E 覆盖点击复选框后 Markdown 从 `[ ]` 切换为 `[x]`，再次点击可还原，并在
  Chromium、Firefox、WebKit 上验证。
- 运行 lint、类型检查、完整单测、构建和相关 E2E。
