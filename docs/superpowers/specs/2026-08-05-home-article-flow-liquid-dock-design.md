# IMX Post Studio 首页、文章工作流与液态 Dock 设计

## 目标

让 Studio 的导航和写作流程符合用户直觉，同时补齐 IMX 主题 Dock 的液态滑块，并消除 Dock 融合中途出现的不透明横向底板。

## 页面模型

应用使用现有单页状态管理，不新增路由依赖。页面状态扩展为：

- `home`：默认首页，展示项目用途、纯本地隐私边界、基本使用流程和 Markdown 常用语法速查。
- `workspace`：文章编辑页。顶部导航“文章”只切回当前编辑区，不创建新文章。
- `dashboard`：草稿库，继续负责打开、复制、重命名、导出和删除草稿。

Dock 中央菜单固定为“首页 / 文章 / 草稿库”，当前页面具有 `aria-current="page"` 和液态滑块停靠状态。右侧在文章页显示“预览文章”，其他页面显示“本地处理”。移动端继续使用折叠菜单。

## 文章生命周期

- 应用启动时仍可维护一个内存中的空白文章对象，但进入“文章”页本身不得把它写入 IndexedDB。
- 只有用户实际编辑、导入或明确执行“保存到草稿库”后，文章才进入可持久化状态。
- 文章页增加独立操作栏：
  - “新建文章”：先安全保存已开始编辑的当前文章，再显式创建新的空白文章。
  - “保存到草稿库”：立即写入当前文章并停留在编辑页，成功后给出明确状态反馈。
- 原有自动保存保留，只对已经开始编辑或从草稿库打开的文章生效。
- 从文章页切换到首页或草稿库时，只保存已经开始编辑的文章；未编辑空白文章不会制造无意义草稿。
- 打开既有草稿、导入并替换、导入为新草稿及失败恢复继续沿用现有安全转换机制。

## 首页内容

首页使用 IMX 现有纸张、圆角、阴影和排版变量，不模仿营销落地页。内容包括：

1. 项目简介：说明这是面向 IMX Hugo 主题的本地文章工作台。
2. 隐私与输出：说明文章和图片仅在浏览器本地处理，最终导出 Hugo 页面包。
3. 三步工作流：编写文章、添加媒体并预览、保存或导出。
4. Markdown 速查：标题、强调、列表、链接、图片、引用、代码块和表格，并展示对应源码示例。

首页提供一个主要按钮“开始写文章”和一个次要按钮“查看草稿”，它们只导航，不隐式创建文章。

## 液态滑块

将 `hugo-theme-imx` 提交 `6f08e8e` 中 `liquid-indicator.js` 与 `navigation-liquid.css` 的核心行为适配为 React Hook，并限定在 Studio Dock 内：

- 桌面端初始停靠当前菜单项。
- 指针进入菜单后，滑块目标跟随指针，在菜单项中心之间连续插值。
- 弹簧计算驱动位移、宽度、拉伸、纵向抬升、轻微倾斜和彩色边缘。
- 指针离开后回弹到当前页面菜单项。
- 页面切换、窗口缩放和菜单尺寸变化后重新测量。
- `prefers-reduced-motion` 下直接跳到目标状态，不运行弹簧动画。
- 移动端隐藏液态伪元素，使用已有的轻量当前项背景。
- Hook 卸载时清理动画帧、观察器和事件监听器。

## Dock 融合修复

当前不透明横条来自统一外壳在三个玻璃块仍相距较远时过早显现，同时 Studio 关闭了主题使用的玻璃模糊。调整为：

- 独立块继续移动并逐步减弱表面、边框和阴影。
- 统一外壳延后到块间距离明显收窄后再淡入。
- 外壳使用更轻的透明表面与 `backdrop-filter`，并在接近完全合并时达到最终强度。
- 外壳和独立块保持交叉淡化，不在间隙中形成实心白色桥接区域。
- 完全分离和完全合并状态保持现有尺寸与位置，移动端不参与融合。

## 可访问性与错误处理

- 所有导航和操作保持原生按钮语义、键盘操作和明确可访问名称。
- 当前页面通过 `aria-current` 表达；滑块仅为装饰，不进入辅助技术树。
- 新建、切页或显式保存失败时继续使用现有失败转换与恢复备份机制，不丢弃当前内容。
- 首页代码示例是静态文本，不执行用户输入。

## 验证

- 单元/组件测试：默认首页、导航不创建草稿、显式新建、显式保存、自动保存启用条件、菜单当前项和液态滑块目标。
- E2E：首页内容、文章/草稿导航、重复点击“文章”不增加草稿、显式保存和新建、桌面滑块移动与回弹、Dock 中段融合透明度、移动菜单无溢出。
- 视觉检查：桌面分离/半融合/完全融合、首页桌面与移动布局、文章页工具栏和移动 Dock。
- 完整门禁：`npm test`、`npm run lint`、`npm run typecheck`、`npm run build`、`npm run check:theme`、`npm run test:e2e`。

## 范围边界

- 不修改 `hugo-theme-imx` 或 `c-x-x.github.io`。
- 不新增后端、登录、云端存储或 URL 路由。
- 不改变导出包、图片处理、预览隔离和现有草稿数据格式。
